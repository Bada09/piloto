# Piloto rhapsody · 6 semanas

Apresentação da proposta de piloto da rhapsody: jornada de 6 semanas, 4 casos de uso e investimento.

## Conteúdo

| Arquivo | O que é |
|---|---|
| `index.html` | Apresentação interativa (3 slides, ondas animadas, painel do spot coaching) |
| `piloto-rhapsody-6-semanas.pptx` | Versão em PowerPoint dos mesmos slides |

## Navegação

- Computador: setas ← → do teclado ou clique na tela
- Celular: os mesmos slides horizontais do computador. Deslize para os lados ou toque nas setas; gire o celular para ver em tela cheia
- Botão ⤢ para tela cheia
- Link direto para um slide: `#s1`, `#s2`, `#s3`

## Publicar no GitHub Pages

1. Envie o conteúdo desta pasta para o repositório (raiz ou uma pasta `piloto/`).
2. Em **Settings → Pages**, escolha a branch `main` e a pasta correspondente.
3. A página fica em `https://<usuario>.github.io/<repositorio>/` (ou `/piloto/`).

> Os valores do slide 3 são estimativas de custo para o piloto.
